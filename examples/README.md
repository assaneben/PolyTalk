# Exemples synthétiques

Les adresses example.test et identifiants fournis sont volontairement non joignables. Aucun secret ou utilisateur réel n'est inclus. Lire [API](../docs/api.md) et [agents](../agent/INTEGRATIONS.md) avant toute mutation.

Pour la CLI, passer le JSON via stdin et remplacer le salon par un salon autorisé. Un exemple n'est pas une fixture préchargée dans le serveur. Ne pas réessayer automatiquement un envoi incertain.
