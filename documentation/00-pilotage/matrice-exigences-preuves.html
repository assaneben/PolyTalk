Vérifications

Recherche locale : 11 tests dédiés réussis et revue indépendante sans défaut critique ou important. Sauvegarde Matrix : récupération par phrase sur un second appareil, import des clés et déchiffrement effectif d’un ancien message réussis (8,52 secondes), puis révocation du second appareil. Test : tests/automatic-backup.integration.mjs.

Lot identité locale : 8 tests de régression inclus dans la suite Node, compilation web réussie, et un test Matrix réel de création, association et reconnexion sur un second appareil (1,55 s). Revue indépendante : nettoyage d’une session reçue après interruption 2FA corrigé et testé. La recette visuelle et matérielle reste à réaliser.

  • Suite Node : 219 tests réussis, diagnostic, contrat OpenAPI et fermeture native compris.
  • Rust 1.99.1, dépendances verrouillées : 14 tests réussis.
  • MCP stdio, client officiel vers Rust et Matrix réels : 1 test réussi, 20.41 secondes, avec le binaire Rust recompilé.
  • A2A local vers Rust, Matrix et API de coordination réels : 1 test réussi, 32.91 secondes, juste après la fermeture MCP.
  • Diagnostic réel : Node, configuration, empreintes web, API et Matrix disponibles.

Ces preuves ne remplacent pas une recette visuelle dans chaque navigateur et sur les appareils physiques. La revue indépendante de ce lot a été interrompue par une limite d’usage après avoir signalé un défaut de compteur ; ce défaut a été reproduit et corrigé par un test de régression. La suite de la revue reste une auto-revue.

Glossaire

Implémenté
Le code existe ; cela ne signifie pas une qualification universelle de chaque appareil.
Qualifié par test
Une vérification identifiée a effectivement réussi dans le périmètre indiqué.
Matrix
Transport de messagerie avec chiffrement de bout en bout pour les salons privés de PolyTalk.
MCP
Interface d’outils utilisée ici en stdio avec un connecteur natif local.
A2A
Protocole entre agents ; PolyTalk possède actuellement un profil de relais local limité.
Runtime
Processus qui exécute les opérations d’un agent ; une messagerie ne suffit pas à créer un agent autonome.
