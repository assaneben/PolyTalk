Créer une identité

Dans la connexion, choisir « Générer une identité locale ». L’identifiant et le nom affiché sont facultatifs : un identifiant est généré si le champ est vide. Aucun e-mail, numéro de téléphone ou portefeuille externe n’est demandé. Un mot de passe de compte peut être choisi.

La clé cryptographique est générée sur l’appareil. Télécharger le fichier d’identité chiffré et conserver séparément son code aléatoire de 32 caractères avant de confirmer l’inscription. Le bouton d’enregistrement du code propose un fichier texte ; ce fichier contient le secret et doit être protégé.

Sans mot de passe choisi, PolyTalk génère un mot de passe technique pour le compte Matrix. Il est conservé dans l’identité chiffrée. Les paramètres permettent de l’afficher explicitement pour les confirmations de sécurité qui le demandent.

Restaurer

Choisir « Restaurer mon identité locale », fournir le fichier chiffré et son code. La restauration vérifie l’installation d’origine puis signe une demande de connexion limitée. En cas d’inscription interrompue avant association de la clé, l’option avancée répare l’association du compte existant. La validation en deux étapes reste exigée si elle est active.

Dans les paramètres, une nouvelle copie chiffrée peut être exportée avec un nouveau code. Cette opération ne révoque pas les anciennes copies. Le fichier d’identité ne remplace pas la sauvegarde chiffrée des conversations : les clés des conversations doivent être restaurées séparément.

Sécurité et limites

Signatures EIP-191/SIWE avec contrôle strict de l’origine, de l’adresse, du but, du nonce et de l’expiration. Aucune transaction financière. La clé privée reste dans le client et les sauvegardes chiffrées ; elle n’est pas envoyée aux routes d’authentification. Le fichier utilise PBKDF2-SHA256 et AES-GCM.

Fermer ou verrouiller un parcours interrompt les opérations et révoque une session temporaire arrivée trop tard. La perte du fichier et du code peut empêcher la récupération de cette identité. Les copies enregistrées sur un appareil compromis ne bénéficient pas d’une protection matérielle garantie.

Le téléchargement cloud automatique et la qualification physique multi-OS ne sont pas réalisés dans ce lot. La recette visuelle complète reste à mener. Ce document ne constitue pas une déclaration de disponibilité générale en production.

Glossaire

Identité locale
Clé de connexion créée et conservée côté client.
Code de récupération
Secret qui déchiffre le fichier d’identité exporté.
Clés de conversation
Secrets distincts nécessaires au déchiffrement de l’historique Matrix.
2FA
Validation supplémentaire facultative activée par le titulaire du compte.
