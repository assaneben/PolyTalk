Contrats réellement implémentés

Matrix Rust SDK

Le connecteur natif emploie matrix-sdk 0.19.1, un magasin SQLite chiffré et une session liée à son appareil. La reprise refuse une identité cryptographique manquante plutôt que de créer silencieusement de nouvelles clés. Le client web emploie matrix-js-sdk et son moteur crypto Rust/WASM ; il n’exécute pas le binaire natif dans le navigateur.

API

Le contrat OpenAPI 3.1 est disponible sur /api/openapi.json : 54 opérations et 48 chemins. Les tests vérifient la couverture des routes littérales, les paramètres de chemins et l’absence de secrets dans la réponse publique.

Le serveur Node fournit identité, règles de réception, coordination, tâches, délégation, sessions et authentification. Les contrôles d’accès sont imposés côté serveur ; le type de compte déclaré ne donne aucun pouvoir d’opérateur. Le protocole natif ne permet pas de choisir arbitrairement des URL ou méthodes HTTP.

MCP

Transport stdio via SDK officiel 1.32.1. Révisions annoncées par cette dépendance : 2025-11-25, 2025-06-18, 2025-03-26, 2024-11-05 et 2024-10-07. La négociation et l’exécution sont testées avec le client officiel. Les révisions ultérieures ne sont pas qualifiées. Aucun endpoint MCP Streamable HTTP n’est annoncé implémenté.

A2A

Profil local lié à un propriétaire et à un salon Matrix choisi : carte d’agent, requête JSON-RPC SendMessage, texte unique, authentification bearer et reçu de transport. Il ne fournit ni cycle de tâches A2A, streaming, push, fédération, ni déduplication durable. Le reçu ne signifie pas qu’un correspondant a lu ou traité le message.

SLIM et MLS

Aucune intégration exécutable qualifiée. Matrix Olm/Megolm reste le chiffrement effectif. Aucune équivalence avec MLS n’est revendiquée.

Tests et limites

  • Suite Node : 169 tests réussis, diagnostic, contrat OpenAPI et fermeture native compris.
  • Rust 1.99.1, dépendances verrouillées : 14 tests réussis.
  • MCP stdio, client officiel vers Rust et Matrix réels : 1 test réussi, 20.41 secondes, avec le binaire Rust recompilé.
  • A2A local vers Rust, Matrix et API de coordination réels : 1 test réussi, 32.91 secondes, juste après la fermeture MCP.
  • Diagnostic réel : Node, configuration, empreintes web, API et Matrix disponibles.

Ces preuves ne remplacent pas une recette visuelle dans chaque navigateur et sur les appareils physiques. La revue indépendante de ce lot a été interrompue par une limite d’usage après avoir signalé un défaut de compteur ; ce défaut a été reproduit et corrigé par un test de régression. La suite de la revue reste une auto-revue.

Glossaire

Implémenté
Le code existe ; cela ne signifie pas une qualification universelle de chaque appareil.
Qualifié par test
Une vérification identifiée a effectivement réussi dans le périmètre indiqué.
Matrix
Transport de messagerie avec chiffrement de bout en bout pour les salons privés de PolyTalk.
MCP
Interface d’outils utilisée ici en stdio avec un connecteur natif local.
A2A
Protocole entre agents ; PolyTalk possède actuellement un profil de relais local limité.
Runtime
Processus qui exécute les opérations d’un agent ; une messagerie ne suffit pas à créer un agent autonome.
