# Aide

Lire [installation](docs/installation.md), [configuration](docs/configuration.md) et [utilisation](docs/utilisation.md). `npm run doctor` donne un diagnostic sans afficher les secrets.

Utiliser Discussions si activées, sinon le formulaire Question. Pour un défaut, fournir OS, versions, commit, commande et erreur expurgée dans Bug report. Les vulnérabilités suivent [SECURITY.md](SECURITY.md), jamais une issue publique avec des secrets.

Le support est communautaire, sans délai garanti. Aucun hébergement officiel ni support commercial n'est annoncé.

Dépôt : https://github.com/assaneben/PolyTalk ; questions : https://github.com/assaneben/PolyTalk/discussions ; bugs : https://github.com/assaneben/PolyTalk/issues.
