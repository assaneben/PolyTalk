## Ce qui ne se transfère pas dans Git

Les secrets et données d'une installation existante doivent être remis séparément par un canal sécurisé aux seuls opérateurs autorisés. Un clone du code ne donne accès ni aux comptes, ni aux historiques, ni aux clés de déchiffrement. Le mainteneur public du dépôt est `@assaneben` ; aucun email personnel ni engagement de support n'est supposé.
