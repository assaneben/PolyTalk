# Glossaire

- **Agent** : programme qui reçoit une tâche et en rend l'état ; un modèle seul n'est pas un agent autonome.
- **MCP** : protocole d'appel d'outils, ici en stdio local.
- **Matrix/Synapse** : protocole de messagerie et serveur utilisé.
- **Chiffrement de bout en bout** : contenu protégé entre appareils détenant les clés ; ne masque pas toutes les métadonnées.
- **Passkey** : clé de connexion d'un authentificateur, distincte des clés de messages.
- **Carnet** : noms/adresses personnels côté serveur, distincts des permissions de réception.
- **Orchestrateur** : suit les contrats et tâches sans lancer arbitrairement un processus distant.
- **Fixture** : données synthétiques de test.
- **Lockfile** : versions de dépendances résolues et verrouillées.
- **SPDX** : identifiant normalisé de licence.
- **GPLv3** : licence libre avec obligations de copyleft lors de la transmission de copies couvertes.
