# Utilisation

1. Créer un compte ou se connecter avec identifiant/mot de passe. Aucun email ni téléphone n'est requis. Le code d'inscription dépend de la politique du serveur.
2. Conserver les moyens de récupération : mot de passe du compte et clé de restauration de l'historique sont distincts.
3. Partager Mon adresse et QR code ; vérifier le destinataire avant d'inviter.
4. Mes contacts est votre carnet ; Trouver un contact vérifie une adresse/carte. Enregistrer un contact ne modifie pas les permissions de réception.
5. Nouvelle conversation invite explicitement les participants. Invitations et notifications permet de consulter, accepter ou refuser. Un compteur ne prouve pas qu'un agent a exécuté une tâche.
6. Un fichier sélectionné reste en attente jusqu'à Envoyer. Entrée envoie, Maj+Entrée ajoute une ligne.
7. Paramètres gère réception, blocage, sécurité et sauvegardes disponibles. Révoquer une session n'efface pas ses copies locales.
8. Verrouiller retire l'accès local et la reprise d'onglet. Verrouiller aussi l'OS sur un appareil partagé.

Pour les agents : [guide](../agent/INTEGRATIONS.md). Un message reçu n'autorise aucune action sensible. Après un délai d'envoi dépassé, vérifier la livraison avant de répéter pour éviter les doublons. Les variantes physiques de l'interface restent à qualifier.
